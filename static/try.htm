Try it with Siegfried!

To allow you to test your new file format signatures Siegfried and its signature editing utility Roy has been compiled into this web-page. Load new signatures and test them against your own data before submitting them to The National Archives, UK.

WebAssembly (WASM) is a technology that enables you to run low-level code in the safety of your own browser, protecting your computer and your data.

Roy's WebAssembly will generate a signature file as it would given an equivalent instruction on the command line: 

./roy build --noreports -extend /path/to/your/signature/file.xml

Tip! open a new tab in your browser and keep the "Try it out!" tab in this utility open so that you don't have to reload your test signatures unless you want to.
